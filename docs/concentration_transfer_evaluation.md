# Concentration-transfer evaluation

The concentration-transfer evaluation tests VIM-2 mutation-effect prediction when one ampicillin concentration is withheld from fitting. The seven concentrations are 4, 8, 16, 32, 64, 128, and 256 ug/mL. The analysis keeps the mutation-group source folds established before model fitting and does not use scores at the withheld concentration to choose model settings.

Concentration is represented numerically as log2 concentration for the fitted sequence and experimental WT-structure ridge models. ESMC and ESM-2 site-difference representations are evaluated on the complete sequence-eligible target population. Experimental-structure descriptor models are evaluated on the matched experimental-structure population. The analysis does not fit new graph, EGNN, or sequence-plus-graph neural models in this analysis; it first tests whether the established sequence and WT-structure information helps with concentration-transfer prediction under the already defined source-only selection rule.

The direct concentration measurements are central comparators. For an omitted concentration inside the measured range, linear interpolation on the log2 concentration scale is the primary reference and the nearest measured concentration is the secondary reference. For 4 and 256 ug/mL, where the omitted concentration lies outside the remaining measured range, the nearest measured concentration is the primary reference and linear log2 extrapolation is secondary. This rule is defined by whether the target dose is inside or outside the observed source range, not by which baseline obtains the better test score.

Paired comparisons use identical target observations within each population. Positive paired differences mean the fitted model performs better than the primary direct concentration reference. Confidence intervals are obtained by resampling mutation groups. A model that does not beat the direct dose-trajectory reference is still informative because the source measurements for the same mutation are part of the biological question being tested.
