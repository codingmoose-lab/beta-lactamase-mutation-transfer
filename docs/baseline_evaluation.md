# Baseline evaluation

Baseline evaluation is the first model-based analysis after biological preparation, task definition, evaluation partitioning, and modelling-input contracts have been defined. Its purpose is to establish how much mutation-effect prediction and transfer can be explained without protein-language models, residue graphs, structure-based inputs, or mechanistic-reference information.

The primary target is `score_analysis`. `score_original` remains an unchanged source measurement and is never a predictor. `score_uncertainty`, protein identity, assay position, source-record fields, structural availability flags, M-CSA information, catalytic-reference fields, and Chen-2024 reported compatibility information are not direct baseline predictors.

The baseline predictors are the training-set mean, mutant-residue mean, WT-to-mutant substitution mean, and ridge regression on WT and mutant amino-acid identity. Chen-2022 concentration-response schemes additionally use a ridge model with quantitative `log2(concentration)`. The concentration transform is estimated from fitting rows only. Hand-selected physicochemical amino-acid scales are not included in these baselines, avoiding additional externally defined amino-acid descriptors.

Ridge regularisation is selected from a fixed logarithmic grid using validation MAE. Nested within-protein schemes select the setting inside each outer fold and evaluate the outer test fold once. Cross-protein schemes select settings using source rows only, refit on all allowed source rows, and evaluate the target-protein test population once. Target-protein test labels never choose model settings.

Reported regression metrics are Spearman correlation, Pearson correlation, MAE, and RMSE. Confidence intervals are calculated after predictions have been generated using 1,000 reproducible grouped bootstrap resamples of the evaluation grouping unit rather than treating repeated measurements as independent. The uncertainty calculation is kept separate from model fitting so ordinary test runs do not repeatedly perform the full resampling analysis.

Condition-transfer tasks also receive source-evidence baselines defined before testing. Antibiotic transfer predicts each test-antibiotic mutation by its mean score across the permitted source antibiotics. Temperature transfer uses the same mutation at the same concentration at the source temperature. Concentration holdouts use both the nearest measured source concentration and a piecewise-linear trajectory in `log2(concentration)`, with the two nearest source concentrations used for interpolation or edge extrapolation. These baselines quantify conservation across the excluded experimental condition without learned protein features.

The 1,513 identical substitutions at the 81 aligned shared-WT NDM-1/VIM-2 positions receive an additional direct biological transfer baseline: the measured source-homologue effect itself is used as the target prediction. This asks how well the simplest possible assumption of conserved mutation effect transfers between protein backgrounds. Target mutation-effect values are used only for testing. The 132 Chen-2024 WT-reversion comparison rows remain separate and are not used for fitting or model selection.
