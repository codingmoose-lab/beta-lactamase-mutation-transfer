# Repository layout

The repository separates executable commands, reusable implementations, tests, documentation, figure sources, and local research data.

```text
beta-lactamase-mutation-transfer/
├── CITATION.cff
├── LICENSE
├── README.md
├── RIGHTS.md
├── pyproject.toml
├── requirements.txt
├── requirements-dev.txt
├── requirements-plm.txt
├── requirements-graph.txt
├── scripts/
│   ├── data/                       01–19: source preparation and task definitions
│   ├── analysis/                   20–55: evaluations, comparisons, and numerical checks
│   └── figures/                    main-figure generators and figure-source inspection
├── src/
│   └── betalactamase_transfer/     reusable scientific Python modules
├── tests/                          unit and integration tests
├── docs/                           scientific methods and execution documentation
├── figures/
│   ├── main/                       Figures 1–6
│   ├── supplementary/              supplementary figures and source-position tables
│   └── components/                 figure components and supporting source files
└── data/
    ├── README.md
    ├── raw/                        source publications, structure files, external records
    ├── interim/                    prepared inputs, model outputs, comparison tables
    └── processed/                  checked observation and residue tables
```

## Research commands

`scripts/data/` contains acquisition and preparation commands, including assay definitions, sequence and PDB numbering, experimental and AlphaFold structures, M-CSA and CARD records, residue descriptors, processed observations, task definitions, and evaluation groups.

`scripts/analysis/` contains the baseline evaluations, sequence and structural models, neural models, held-out-condition and concentration studies, biological analyses, source-protein comparisons, source-position holdouts, file-integrity checks, and numerical-result checks. Commands 45–55 cover the later position- and source-fitting evaluations. The executable paths are listed in the top-level [README.md](../README.md).

`scripts/figures/` generates main figures 2–6 and Supplementary Figure S12. Figure 1 contains manually composed scientific components; its final figure must not be regenerated by unrelated figure commands. Supplementary figure generation is documented in `scripts/figures/README.md`, with source-position tables under `figures/supplementary/source_position_predictions/`.

## Reusable Python code

`src/betalactamase_transfer/` contains separate modules for measurement preparation, residue mapping, feature construction, predictive models, training and evaluation, paired uncertainty calculations, biological analyses, and source-position comparisons. Modules can be used by the numbered commands without requiring the corresponding model computations to be repeated.

## Data directories

- `data/raw/` stores downloaded experimental sources and other third-party records, including Chen et al. DMS workbooks, RCSB PDB structures, UniProt records, AlphaFold structures, M-CSA, and CARD records.
- `data/interim/` stores prepared assay and structure tables, model inputs, predictions, training records, performance comparisons, grouped uncertainty calculations, and source-position results. Most files here are generated by individual research commands and can be large.
- `data/processed/` contains checked observation tables and residue features used for model evaluations.

These three scientific data directories are excluded from the published source-code Git history. Access to original experimental data and permission to redistribute generated tables containing copied measurements are separate questions. See `data/README.md` and `RIGHTS.md`.

## Figures and manuscript

The main and supplementary figure PDFs are kept in `figures/main/` and `figures/supplementary/`. Editable figure sources and components are maintained separately, including files ignored by Git. Some supplementary figures are composed from saved data rather than regenerated when the repository is checked.

The journal manuscript and its Supplementary Information are maintained separately from the executable research repository. Neither a `manuscript` directory nor a manuscript-discovery script is required inside this repository.

## Tests and documentation

`tests/` contains focused and integration tests for the modules. `docs/` describes assay definitions, residue numbering, structure selection, model comparisons, held-out evaluation tasks, source-protein fitting restrictions, numerical checks, and execution requirements.

The software and scientific data have different redistribution conditions. See `LICENSE`, `RIGHTS.md`, and `CITATION.cff` at the repository root.
