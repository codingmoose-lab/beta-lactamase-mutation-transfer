# Condition and concentration biological analysis

Stage 41 summarizes the completed VIM-2 condition-transfer and concentration-transfer results. It does not fit another predictive model and does not choose a new setting from held-out outcomes.

The analysis keeps three questions separate. First, it compares the best already-fitted sequence or experimental-structure model with the predeclared direct same-mutation reference for each test. Second, it compares the two direct concentration references, distinguishing interpolation from the two boundary tests. Third, it summarizes how individual mutation effects change across the seven measured AMP concentrations and then summarizes those mutation trajectories by assay position.

The concentration series is 4, 8, 16, 32, 64, 128, and 256 µg/mL. Each dose is twice the preceding dose, so log2 concentration gives the equally spaced values 2 through 8. This follows the measured twofold dose series rather than introducing arbitrary numerical spacing.

Mutation trajectories use one target outcome for each mutation and measured concentration. They report score range, endpoint change, slope per one log2 concentration step, rank association with concentration, and the largest adjacent change. Position summaries are descriptive summaries of those mutation trajectories. The analysis does not treat position-level quantities as if every repeated mutation or dose were an independent position-level observation.

Stage 41 reuses the paired uncertainty intervals already calculated by Stages 39 and 40 for model-versus-reference comparisons. It does not rerun bootstrap sampling or replace earlier result files.
